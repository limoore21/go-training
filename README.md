# Go Training

Перехожу с PHP на Go. Понял, что хочу спуститься на уровень ниже - в системное программирование, сети и реальную архитектуру.

Здесь я храню свой прогресс: решаю задачи, набиваю мышечную память на строгую типизацию и собираю микро-утилиты, которые можно использовать в работе.

### Что сейчас в разработке (Микро-проекты)

- **Сетевой мониторинг** (`04_projects/HTTP_Health-Checker.go`): Пингует пачку урлов и чекает статусы через net/http.
- **Анализатор логов** (`04_projects/log analyzer.go`): Заглушка под будущий парсер логов. Сейчас умеет считать количество запросов с разных IP через мапы и выдавать бан спамерам. В планах прикрутить чтение реальных access.log и многопоточность.
