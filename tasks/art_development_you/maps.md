# maps.go

Файл `maps.go` содержит примеры работы с картами (map) в Go. 
Карты — это структуры данных, которые хранят пары ключ-значение. 
В Go карты создаются с помощью ключевого слова `make`, а элементы добавляются или изменяются с помощью операции присваивания. Карты позволяют эффективно находить и обновлять данные по ключу.
