# pointers.go

Файл `pointers.go` содержит примеры работы с указателями в Go. 
Указатели хранят адрес памяти переменной и позволяют изменять значение переменной по ссылке. 
В Go указатели создаются с помощью оператора `&`, а разыменование выполняется с помощью оператора `*`. 
Указатели используются для передачи данных по ссылке и оптимизации памяти.
