# Микро-задача 1: «Коварный срез» (Slices & Pointers)

## Тема
Слайсы, передача по значению, `append`, `len` vs `cap`.

## Условие
Что выведет следующий код и почему?

```go
func UpdatePorts(ports []int) {
    ports[0] = 8080
    ports = append(ports, 9000)
}

func main() {
    serverPorts := []int{80, 443}
    UpdatePorts(serverPorts)
    fmt.Println(serverPorts)
}
```

## Ответ
Выведет: `[8080 443]`

## Объяснение
- Слайс передаётся **по значению** — в функцию попадает копия заголовка слайса (указатель на массив + len + cap).
- `ports[0] = 8080` — пишет напрямую в базовый массив → изменение **видно снаружи**.
- `append(ports, 9000)` — создаёт новый массив и обновляет локальную копию заголовка. Оригинальный `serverPorts` в `main` остаётся с `len=2`, поэтому `9000` снаружи **не виден**.
